## Transfer and persistence baseline

- A local pyftpdlib 2.2.0 fixture provided plain FTP, explicit FTPS and a separate throttled FTP listener on `127.0.0.1`. Its independent client verified that wrong passwords receive `530`, FTPS rejects unprotected control and data connections, and an aborted upload retains a partial first file without creating a second file.
- The `52c10e6` package's `ftpapi` and jFTP SSL configuration then connected to the local servers from a standalone Java process. For each protocol, the wrong password was refused, the start directory marker appeared, and a 65,536-byte binary upload and download matched SHA-256 `58932fb6a02052150eb5b2f31c55a779c12ed1650760243ab98a20053366f5fb`. The FTPS fixture required encrypted control and data channels. The test certificate was trusted through an isolated application trust store.
- The baseline package wrote synthetic settings and a sealed favorite to a temporary home, then reloaded both in a fresh JVM. A separate baseline home held a plain serialized favorite list, which the baseline loaded and migrated to the sealed format. Both original homes were retained for replay. The baseline serial descriptors record the field names, types and version IDs for `JFTPPreferences`, `RemoteHost` and `Favorite`.
- A separate Java 25 package loaded both baseline homes, including the sealed favorite and migration of the plain list. All three classes' serialized field names, types and `serialVersionUID` values matched the baseline. Replay on the integrated build and packaged desktop transfer flows remain open.

## Stage 2 isolated checks

- The applet and inactive macOS adapter candidate built with all 11 tests passing. Its JAR contains the desktop and reflective macOS classes and excludes both retired classes. The POM no longer declares the Apple compile dependency. Its desktop check is pending.
- The Java 25 build candidate passed `clean verify` on Temurin 25.0.4.1, including with an empty Maven cache. All 229 compiled application classes had major version 69. The corresponding release 8 build had major version 52. Maven rejected Temurin 21.0.13.1 at `validate` through the Enforcer version range `[25,26)`. The three distributions agreed on files, launcher filtering and POSIX permissions, and the manifest and runtime resource contents passed the package check.
- The Jupiter candidate discovered all 11 cases via Surefire's JUnit Platform provider. With the pre-fix macOS popup path from the parent of `14e62ce` selected in a scratch build, two cases failed with the original selection `[0, 1]`. They expected `[2]` and `[]` respectively. The selected-row case passed. Restoring the fixed source brought the suite back to 11 passes.
- A combined Java 25 and Jupiter snapshot passed `clean verify` with an empty Maven cache. The full 11-case suite, package layout, manifest and runtime resources passed.
- The local-browser candidate changes only the table model and its containing pane. The original and candidate produced identical table-model results for a synthetic file, including a `Long` byte count and a `Date` modified column. All 11 cases passed, and native navigation and status checks remain open.
- The baseline archive helpers fired begin, progress at 25%, 50%, 75% and 100%, then end on a 65,536-byte file. Extracted bytes matched. An output path conflict raised `FileNotFoundException` after begin and end callbacks, with no progress. The unzip end callback reported the archive name in both cases.
- The persistence baseline created default settings and an empty favorite file on first use. Invalid and wrong-type settings fell back to defaults and left the original bytes intact. Invalid favorites raised `StreamCorruptedException` and a wrong-type favorite record raised `ClassCastException`. Writes to either record failed when the destination was a directory.
- Temurin 21.0.13.1 wrote the baseline settings and both favorite formats. The combined Java 25 package reloaded the settings and sealed favorite, migrated the legacy list, and matched the baseline descriptors. The Java 21 runtime rejected the Java 25 package before startup.
