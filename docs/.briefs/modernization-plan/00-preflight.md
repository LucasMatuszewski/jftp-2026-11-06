# Review the modernization preflight

Plan: docs/modernization-plan.md
Task: 00-preflight

Read the [plan's preflight checklist](../../modernization-plan.md#preflight) and the [repository instructions](../../../AGENTS.md). Inspect the product and architecture documents linked by the plan and the current build and test configuration. Record the current Git revision and existing local changes before comparing them with the baseline cited in the plan.

Keep the assignment read-only. Verify each item in the preflight checklist and report any conflict that changes scope, architecture, or acceptance. Identify what local startup work already exists, which stage 1 requirements it could satisfy, and what verification still remains.

Return the revision, relevant changed paths, and findings with file references. If a check is blocked by missing evidence or a conflicting decision, identify the affected stage and the prerequisite or decision it needs. Send the report to the lead before stage 1 starts.
